# Error Handling

Example:

```json
{
  "success": false,
  "message": "Resource not found",
  "data": null,
  "timestamp": "2026-08-26T05:24:47"
}
```

| Code | Meaning |
|---|---|
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 409 | Conflict |
| 500 | Internal Server Error |
