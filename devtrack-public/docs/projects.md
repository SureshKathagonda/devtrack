# Projects API

- `POST /api/v1/projects` — Admin, Manager
- `GET /api/v1/projects` — Admin, Manager
- `GET /api/v1/projects/{id}` — Project access
- `PUT /api/v1/projects/{id}` — Admin, Manager
- `DELETE /api/v1/projects/{id}` — Admin, Manager

Project ownership and membership rules are enforced by the API.
